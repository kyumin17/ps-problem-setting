\begin{problem}{통행 제한}{standard input}{standard output}{2 seconds}{512 megabytes}

$N$개의 마을로 이루어진 나라가 있다. 나라에는 $M$개의 도로가 있으며, 각 도로는 서로 다른 두 마을을 양방향으로 연결한다. 도로를 지나는 데에는 일정한 시간이 걸리고 어떤 두 마을을 직접 연결하는 도로는 최대 하나만 주어진다.

이 나라에서는 야간 통행 제한 정책을 시행하고 있다. 각 마을에는 통행 제한 시각 $R_i$가 정해져 있어 시각이 $R_i$보다 늦어지면 해당 마을에 들어가거나 나갈 수 없다. 즉 마을 $i$는 정확히 $R_i$까지는 출입이 가능하고, $R_i$를 초과한 시각에는 불가능하다.

여행자들은 목적지에 최대한 빨리 도착하고 싶어 한다. $Q$개의 여행 계획에 대해 출발지 $S$, 목적지 $D$, 출발 시각 $t$가 주어진다. 여행자가 시각 $t$에 마을 $S$에서 출발할 때, 통행 제한을 위반하지 않고 마을 $D$에 도착할 수 있는 가장 이른 시각을 구하여라. 출발지와 목적지가 같은 경우는 주어지지 않으며, 목적지 $D$에 도착할 수 없다면 $-1$을 출력한다.

\InputFile
첫째 줄에 마을의 수 $N$과 도로의 수 $M$이 주어진다. ($2 \le N \le 500, 1 \le M \le \frac{N(N-1)}{2}$)

둘째 줄에 각 마을의 통행 제한 시각 $R_1, R_2, ..., R_N$이 주어진다. ($1 \le R_i \le 10^9$)

셋째 줄부터 $M+2$번째 줄까지 각 도로의 정보 $u_i, v_i, c_i$가 주어진다. ($1 \le c_i \le 10^6$)

이는 마을 $u_i$와 $v_i$를 연결하는 도로이며, 도로를 이동하는 데 $c_i$만큼의 시간이 걸린다는 의미이다.

다음 줄에 쿼리의 개수 $Q$가 주어진다. ($1 \le Q \le 10^5$)

이후 $Q$개의 줄에 걸쳐 각 쿼리 $S_i, D_i, t_i$가 주어진다. ($1 \le t_i \le 10^9$, $S_i \ne D_i$)

\OutputFile
각 쿼리에 대하여 $D_i$에 도착할 수 있는 가장 이른 시각을 한 줄에 하나씩 출력한다. 단, $D_i$에 도착하는 것이 불가능하다면 $-1$을 출력한다.
